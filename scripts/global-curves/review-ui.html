计算范围与数量规则

己方礼装张数 ≤ 己方实际上场人数；助战最多一张礼装，单独计算，不能借助战位置多带一张己方礼装。无助战最多六名己方，有助战最多五名己方。允许空位和空装，15 绊满级成员仍可携带礼装。所有礼装都是全队效果，交换佩戴者不改变羁绊函数，成员表给出一组合法的佩戴示例。

每条配置同时说明“每张礼装命中多少名己方上场从者”和“其中多少名能领取羁绊”；满级成员虽有匹配特性，但不领取加成。助战本人不领取羁绊，不计入命中人数，助战礼装和前排助战的第一层效果分别展示。

理论图鉴范围内每种礼装最多一份，同效果不同礼装可叠加。己方肖像上限表示允许枚举 0 至该数量，并非强制携带；若账号只有一张，请设为 1。满破与未满破 COST 相同，自由持有范围内满破逐人不劣。15 绊身份自由选取，具体账号的持有、满破份数及已满级身份不在本页约束中。

选定从者后在浏览器后台重新求解，可能需要较长时间；条件变化会取消旧计算。普通助战身份不影响羁绊，按助战位置和礼装比较；活动全队光环遵守资料中的助战适用规则。本页不判断战斗能否通关，不含冠位奖励槽或锁定位置。
