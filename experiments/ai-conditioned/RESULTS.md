# 条件化配置模型 v2：本轮结果

**已训练出能在本轮 20 类库存场景中提出接近最优配置的离线混合模型；尚不能保证每次最优，也尚未达到软件提速接入条件。** 教师和验收默认不限时，先前 3 个超时条件已完成。没有上传训练数据集，没有替换软件默认模型。

## 模型和样本

75 维当前条件/已选前缀输入，分别训练 75→64→32→7 和 75→128→64→7 的 ReLU 网络。以验证损失选择 128/64 隐层版本 `conditioned-v2-128-ce4851b184c0`，验证教师强制前缀下的单步分类准确率约 86.05%；这个指标不等于配置成功率。

训练包含 8,512 个可行库存查询、37,678 个条件化数量选择步骤。完整验证使用 2,400 个条件：2,000 个库存条件中 1,688 个可行、312 个没有可行教师答案，另 400 个通用特殊规则单列为不适用。输入覆盖20类场景，包含CN/JP全从者目录，但礼装目录规模主要仍为3–7种。

模型不直接输出最终分数。先提出完整礼装数量组合，再调用原身份/形态/COST/站位 DP 补全整支队伍，独立重算得分和合法性。所有候选仍标记“近似，未证明最优”。

## 配置质量

分数比 = 候选经核实的真实羁绊得分 / 同条件完整精确最优得分。以下为 AI 排名前32的组合；均采用 beam=128。每个组合中的从者分配由约束DP求得。

| 指标 | 完整验证集 | 新种子独立资格集 |
| --- | ---: | ---: |
| 可行库存条件 | 1,688 | 857 |
| 返回可行配置 | 1,688 | 857 |
| 平均分数比 | 99.9837% | 99.9927% |
| 达到精确最优分数 | 1,677 / 1,688 | 852 / 857 |
| 达到最优分数的99%以上 | 1,683 / 1,688 | 855 / 857 |
| 达到最优分数的95%以上 | 1,686 / 1,688 | 857 / 857 |
| 最低分数比 | 87.6847% | 97.4427% |

验证时额外的零自有礼装兜底将最优分数条件提高到1,678个、99%以上提高到1,684个；独立集兜底没有改变上述结果。最终独立集852个条件同时达到了精确最优分数与COST，仍有5个不是最优。

独立资格集在模型和候选参数确定后用新种子42000000生成，共1,200个条件：1,000个库存条件（857可行、143无可行教师答案），200个通用规则不适用。它不参与训练或调参。旧32000000封存集没有用于本轮模型质量/性能评估。完整验证与独立资格集都没有核验错误、异常或超时，没有出现候选得分超过精确答案的情况。

## 与旧模型的公平候选预算对照

采用旧16维独立礼装模型作为控制，同样使用合法性屏蔽、beam=128、最多32个组合、同样的DP补全和零礼装兜底，不拿旧模型只检查两个候选来比较。

| 独立集857个可行条件 | 旧独立偏好模型 | 新条件化模型 |
| --- | ---: | ---: |
| 平均分数比 | 99.6828% | 99.9927% |
| 达到精确最优分数 | 766 | 852 |
| 达到最优分数的99%以上 | 796 | 855 |

新模型89个条件得分更高、2个更低，其余766个同分。没有对低分结果作删除或替换。比较的含义是同候选预算下的配置质量改善，不是纯神经网络与精确算法的速度胜出。

## 避免把穷举当作AI收益

独立集467个条件的合法数量组合域不超过模型候选预算，检查了整个数量域。这些条件不能独立证明模型选择能力。在剩下**390个只检查部分数量组合**的条件中，新模型385个达到最优分数、388个达到最优值99%以上。补全阶段仍会精确优化每个已选择组合中的成员与位置。

验证集中仍有极端低分，最低约87.68%，所以不能承诺所有约束都能得到99%以上。冠位、系统NPC、通用特殊锁定、指定目标活动四类路径尚未训练该数量策略，继续使用原精确路径；不适用条件没有计入AI成功率。

## 耗时与是否接入

独立集新流程中位耗时约16.51ms，其中提案阶段约8.74ms；同批条件的直接完整精确求解中位数约4.94ms。本轮是离线质量验收，包含不同难度的混合样本、单次观察，不能推广为设备速度结论；也没有显示产品提速。

因此本轮保留模型和方法，不替换2.1.1的默认模型，不打开旧封存集的产品性能验收，不启动三版本接入比较。下一步需降低提案/补全开销、改进极端样本，并扩展四类通用特殊规则。75维/128单元网络也不兼容现有featureVersion=1的更新接口，不能把它直接塞进软件更新清单。
