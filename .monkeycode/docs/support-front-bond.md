# 助战前排 +4%：冲突裁定

后写的验证清单与原公式冲突时，以原公式为准。本条是其中一处。

## 原公式（权威）

实施说明书 / MEMORY 公式原文：

- 己方前排第一层 +20%
- 助战占前排（1–3 号位）时，己方全体再叠 +4%：前排合计 24%，后排 4%
- 助战在后排、或没有助战占前排时，后排第一层 0%，前排仍是己方 +20%
- 助战本人不拿羁绊

自动推荐勾选留助战位后，助战固定 6 号后排，只给助战礼装，不上从者。这时第一层按「前排己方 +20%、后排 0%」结算。

## 清单里的笔误

`FGO_Solver_AI_验证与疑问清单.md` 第 12 节曾写：

```text
Support Back = +4%
```

这不是原公式。助战在后排时第一层不加这 4%。

同一节的 `Support Front = 普通 Front +20% +额外 +4%` 与原公式一致。

## 代码怎么做

- `src/bond.js`：`calcParty` 只在助战 `position <= 3` 时给己方加 `SUPPORT_FRONT_SHARE`（4%）
- 手动把助战拖到前排：走原公式，前排 24%、后排 4%
- `recommendTeam`：助战固定 6 号，实算 20%/0%
- Upper Bound：仍按可能出现的 24%/4% 放宽，避免低估

不要为了迁就清单去改公式。
