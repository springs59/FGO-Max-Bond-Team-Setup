# 一页式实时结果与跨关卡队伍档案

修复一页式布局中先进入队伍对比、再开始查询时，后台已有合法队伍及最高分证明而推荐区仍为空的问题。流式结果会刷新已显示的推荐区，保留对比编辑框的未提交文字、焦点、选择区和视口。首屏显示异常也提供可见提示。

加入对比时保存每队独立的结果：关卡、区服、账号标签、基础羁绊、COST、茶壶、光环、目标、主练与锁定、筛选、冠位使用前提、六个位置的从者/灵基/礼装/满破、逐位收益、总收益和计算状态。只保存被选中的六个物理位置及结果，不附带完整账号、图鉴或求解方案集合。

切换关卡、账号、活动、基础羁绊和茶壶，不会改写已保存队伍的收益、名称、插图及条件。刷新和本机规划备份保留这些记录。同一支物理队伍在不同关卡或条件下可以分别加入，不被错误去重。

所有对比队伍可一次导出单个 HTML、JSON、PDF、Word 或 PNG 长图；每支队伍使用自己的条件与收益，含需要先完成冠位选择的说明。图片和 PDF 根据各队条件文本自动增加高度，避免长条件挤掉后排成员。历史档案仍可打开。

直接编辑/交换站位后明确按当前关卡和账号重新结算保存，不继承旧最优证明。复制保留原结果且副本可以独立修改。没有保存过原条件的旧对比记录无法恢复历史条件，界面与导出会说明按当前/导出时条件结算，不能伪造原关卡收益。

验证包含完整 npm test、跨条件收益冻结/恢复/去重/编辑/冠位前提单元检查，以及真实页面回归：冠位剑加入对比 → 一页式仍在对比区启动冠位弓并限制 4/5 星 → 在同分补全未完成时立即展示队伍 → 切换当前条件后逐一导出五种格式 → 打开 JSON 档案 → 刷新后保留两队原始收益。页面验证由仓库 CI Chromium 执行。
