# 推荐进度与曲线查询修复

COST 上限 20、六名从者（第一名 COST 3，其余 COST 16）、无礼装、基础羁绊 1000 的最小案例，旧通用搜索先用超预算的五人暖启动队伍记录 5600，最终才过滤到合法的两人队伍 2400。超预算的记录也参与剪枝，因此不只是显示错误。

现在在暖启动、装备组装、预计算种子及最优记录进入搜索前核验 COST。进度只报告当前条件下实际可行的分值，茶壶倍率与最终结算一致；主练目标单独显示主练分值及对应总羁绊。

普通曲线效果求解支持锁定从者、灵基、前后排位置、空位、无助战至多六人、强制六人及固定好友助战位置。有效活动光环按“实际选择的不同身份贡献总量”作为 DP 状态；同一身份的多个灵基仍互斥。二十名同样提供 5% 光环的从者不会枚举二十个身份的全部子集，至多六人对应七种光环总量。

主推荐先证明当前目标的全局最优，无需等所有较差助战分支都各自求到最优。附加队伍标明是可行候选；选择另一助战礼装会按该礼装约束重新精确求解，不能把筛选后的候选冒充新条件的最优。完整逐助战分支最优模式仍可用于离线验证。

后台推荐线程原先只能保留内存缓存，无法使用 localStorage。现将完成的查询保存在 IndexedDB，最多保留二十条，绑定区服、账号、持有、满破、羁绊状态、条件、礼装效果及数据版本；重启线程或软件后可复用相同条件。修改条件或数据不复用旧答案。旧缓存修订号失效，不删除账号和数据预计算缓存。

本次并未把自由图鉴的匿名曲线上限当作账号答案，也没有宣称任意账号与任意约束的全部基数包络已经离线完成。新基数需要按当前条件精确结算效果；复杂指定佩戴、主练多目标、冠位与固定 NPC 条件仍使用通用求解。普通条件优先采用曲线效果 DP；相同已完成条件直接复用本机结果。
