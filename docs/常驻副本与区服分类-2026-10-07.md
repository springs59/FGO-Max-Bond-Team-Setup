# 常驻副本、解锁要求与区服分类

国服与日服使用各自的 Atlas 快照，不互借活动、关卡、从者和礼装数据。
分类算法通用，但需要读取对应服务器的元数据和结束日期占位值。

本次核对确认：CN 长期活动使用 2145888000（2038 年）占位，JP 使用
1893423600（2030 年），部分 JP 常驻关卡的结束日期更晚。此前仅识别 CN
占位值，导致 JP 的 SE.RA.PH、虚数大海战、冥界圣诞等被误归入当前限时活动。
携带 eventId 的所罗门、Lostbelt No.7 和终章也受到了影响。

## 分类依据

- 章节 flags 中的 mainScenario：主线章节，不能因为附带 eventId 就当作限时活动。
- parentWarId 1004，以及两服各自的主线物语标题：主线物语常驻内容。
- 其他永久结束占位值的 eventQuest：常驻活动内容。
- 真正有近期结束时间的活动：限时活动；再按实际开放窗口筛选。
- quest afterClear 独立标记一次通关、可反复挑战或定期重置。

显示索引另存上述分类与 releaseConditions，不改变羁绊加成结算公式。
两服分别从 nice war 的 spots / quests 读取解锁条件。实查 JP SE.RA.PH
关卡 94050999 存在 purchaseShop（6000420）及 questClear（1000822）条件。
页面提示含购买/兑换条件、前置通关和账号解锁未核验，不推断玩家已购买，
也不据此声称一定需要付费兑换（商店项目可能免费开放）。

## 页面与更新

增加「常驻 / 主线物语」，「当前活动」明确改名为「当前限时活动」。
「当前开放」改为「时间范围内」，注明它不等于账号可进入。
CN 原管线未收集永久活动章节，现和 JP 一样补齐对应永久章节与解锁资料。
每次数据刷新都使用对应服务器的活动和章节重新分类，保留独立图鉴和条件。

来源为 https://api.atlasacademy.io/export/CN/basic_war.json、对应 JP 导出，
两服 nice_event.json、nice/{region}/war/{id} 及 basic quest phase search。
关卡羁绊仍以 raw mstQuestPhase.friendshipExp 为准，不直接使用 basic bond。

回归验证包括两个结束日期占位值、带 eventId 的主线、购买条件、跨服隔离、
常驻分类不进入限时筛选，以及现有全套测试与索引验证。
