# 三小时全量重跑协议

- 请求：20261022-full-rerun-3h；每个查询的求解段最多10,800,000毫秒，启动与报告保存另计。
- 条件：沿用上一轮全部15种条件；关闭AI、经典高起点AI、扩展策略AI、大数据神经AI各自测试。
- 同一条件在一台Ubuntu主机上运行；四种选择各使用一个独立CPU核心，所有现存线程均设置并复核绑定。四个短测同时进行，随后四个3小时查询同时进行；每次使用新进程、关闭结果缓存。
- 每格先跑15秒普通短测或45秒压力短测，再进行3小时长测。跨主机、历史归档的绝对时间不直接混合排名；同机短/长测以固定输入、模型、源代码和CPU绑定配对。
- 固定到触发请求时的PR源提交，不跟随main或每日数据更新。保存输入SHA256、图鉴/引擎Git blob、环境、推理次数、起点与当前最高分、完整性、同分计数和指纹、搜索工作量、耗时和峰值RSS。
- 记录15秒、45秒、1/5/15/30分钟、1/2/3小时进度；每半小时保存独立检查点，任务收尾时上传完整分格记录。只保存数字和指纹，不保存全部队伍的大文件或历史账号抓包。
- 另外重跑完整npm测试、1,000组独立穷举、原生安装/升级检查、数据/索引验证、七轮同机性能对照，以及全部原有和新增浏览器回归。
- 已完成结果的最高分、全部同分数量和指纹必须一致。缺格、异常、回归失败或矛盾结果均标为失败。超时保留部分结果，绝不当作最优证明或完整同分列表。
- 运行结束后自动生成Markdown/JSON对比报告并保存到本测试分支；不合并main或发布安装包。若自动写回失败，完整报告仍保留在Actions附件。
