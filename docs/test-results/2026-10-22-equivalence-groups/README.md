# 最高分配队的等效合并（2026-10-22）

在搜索阶段合并对当前查询数学等效的从者/形态、相同 COST 与结算效果的礼装，以及未锁定的前排内部、后排内部整体换位。结果保留一个合法代表与可恢复的替换池，继续覆盖全部最高分队伍；不同 COST 的同分方案不会按较贵而删除。途中其他合法方案仍只收集搜索中遇到的结果。

## 合并与正确性

- 身份只在完整的可用形态效果分组一致时共享替换池；必带、主练、指定位置和指定礼装持有者隔离。指定形态的可用性参与分组签名。
- 比较本查询所有候选礼装对形态的实际命中效果，而不是只比较当前分数。各槽位共享“从者不能重复”及礼装 ID/满破状态库存约束，不能独立做笛卡尔积。
- 站位只合并相同前/后排结算位置；固定助战、空位锁定和其他位置约束不参与互换。
- 分数上界仍使用真实身份数量计算光环潜力；同一替换池在代表身份已使用后仍可用其余身份，避免低估上界造成漏解。
- 涉及相关实时活动、冠位、固定 NPC、本人效果等尚未证明可合并的域，保留原来的逐队精确搜索。不会为强行压缩而改变规则。
- 不使用 Top-K 或同分 COST 支配删除。合并是可逆表示，不是只留下少量代表而丢弃其他身份。

## 展示与导出

分页数量单位为“组”，每组展示一套合法代表，并列出可替换的从者/形态、礼装及可整体互换的位置。替换必须遵守联动约束，编辑后重新结算。

默认 JSONL 导出升级为版本 2：头部只存一次域替换目录，组记录保存代表、引用及库存约束；不会导出时自动展开所有变体。`expandScoreTeamFamily(record,catalog)` 提供按需、逐条的合法展开，供审计或选定组使用。未能证明等效的域作为单成员组保留。

## 正确性与回归

- 完整 npm test 通过。
- 20组定向展开对照：19,332套最优物理队伍一致且没有跨组重复。
- 1,000组独立穷举：684,918个候选、232,234套最高分物理队伍一致。
- 真实浏览器：65组OPFS跨页、导出、等效选项、取消、缓存复用与320/390/834/1440布局通过。
- 队伍比较与替换、账号导入与持久化、AI选择和模型更新界面通过。
- 三小时控制器自测通过；该自测使用10秒/1毫秒样例，不是三小时压力重跑。

独立随机对照的逐例输入与预期集合可由 `scripts/check-all-score-teams-random.mjs` 复现；该脚本现在先将组按需展开，再与独立物理槽位穷举对比，并验证精确结算与无重复。汇总见 [random-summary.json](random-summary.json)。旧的物理枚举单元测试通过审计开关保留，组版本另有定向检查。

旧三小时测试采用的 `dense-zero` 合成例（20身份）现在可完整搜索为 **1,186组**，本机预热后三轮搜索中位约 **10.50 ms**。未在该压力例上物理展开全部队伍；小域独立穷举和定向检查验证可逆合并规则。此数字不包含 OPFS 与渲染，不能解释为全图鉴已经完成。

## 有限时的四模式矩阵

本轮沿用15条件×4种AI选择，普通用例上限15秒、压力例5秒。**52格完成、8格达到时限**；完成格要求最高分、组数与组记录指纹一致。原始记录明确标为 `equivalence-groups`，不能与旧版物理队伍数量直接比较。旧三小时记录没有覆盖或重写。

国服/日服开放搜索仍未在这次短时限内完成；另一次关闭AI的国服开放30秒试跑也未完成，不能宣称已证明最高分或收齐所有组。合并解决了大量等效变体的展开成本，最重场景的最高分证明仍存在开销。这次没有重新跑三小时矩阵。
