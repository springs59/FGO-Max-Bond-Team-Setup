# 内存修正补跑协议

原统一测试条件、固定版本和代表解/全部同分的口径见[原协议](../2026-10-22-historical-3h/PROTOCOL.md)。

本轮只重跑CN-open、JP-open，采用8个“待测版本＋当前关闭AI”配对；两个进程分占同机两个核心。依据物理内存及cgroup中的较小值，预留至少2 GiB且不少于15%的内存，再预留10%给堆外分配；剩余均分，向下取256 MiB整数倍，每个进程最高6144 MiB。预算不足2048 MiB时拒绝启动，避免再次采用明显过低的堆限制。

记录实际预算、堆上限、父进程采样的VmHWM和退出状态。V8堆OOM只根据明确日志判定；其他SIGKILL不冒充已确认OOM。每次查询仍限时10800000毫秒；原生算法和模型不修改。Node固定24.22.0，同机时间比不混合原768 MiB配置。

合并报告保留原轮117种其他条件结果，以及全部原轮压力结果；新18种压力版本组合必须逐项核对输入和运行源文件指纹。缺失数据、配置不符或源文件改变均不能生成通过结论。补跑失败仍如实记录，不以旧成功值静默替代。
