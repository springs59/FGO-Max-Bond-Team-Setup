# 起点提前结束与独立队伍对比

本改动基于区间剪枝提交 `0ae9b27`。2026-10-17 用户授权将功能分支合入 main，并将合并版本作为第四个固定版本加入性能矩阵。原三版本宽矩阵仍使用原固定源码快照，结果单独保留；本次不改变发布版本号或安装包。

## 起点核实：保持原下界质量

“当前最好”指已找到的最好合法可行解。模型预测不能成为下界。首次改善也不能证明该起点继续搜索不会得到更高下界，因此“首次改善就停”与“初始下界不弱于完整核实”不能无条件同时保证。

本次实现采用保守规则：最多两个原有礼装起点，在身份 DP 每轮的压缩前沿中检查完整合法队伍。只有其分数达到该助战／位置分支的安全分数上界，同时 COST 达到独立身份和必选成员约束下的成本下界，才结束当前起点的该分支核实。未满足证明条件时，沿用完整精确核实。

证明依赖如下：

- 见证必须包含所有必选身份，满足最低己方人数、至少一名己方前排、当前礼装装备人数、前后排和预算约束，且实际光环和与当前光环假设一致。
- 光环假设由大到小搜索。当前放松上界已被实际队伍达到，后续较小光环的上界不能更高。
- 成本下界取每个独立身份最便宜形态，先保留必选身份，再补足所需人数。它放松站位，不会高于任何合法队伍的最低成本。
- 同时达到分数上界和成本下界，意味着该分支继续核实不能提高分数或改善同分 COST；每种助战／位置仍分别处理。
- 提前结束的起点不加入“已经完整遍历”的复用列表。正式搜索仍会处理它，且继续保留上界等于下界的分支。
- 有逐候选回调的调用保留原完整起点过程，避免省略它需要的候选通知。

新增诊断 `seedCertifiedStops`、`seedPendingRechecks`。正常 DP 状态转移循环保持原有操作，达界检查位于起点探测的轮间前沿。AI 策略修订号升为 4，隔离旧 AI 结果缓存；关闭 AI 的策略键仍为 `off`。

这不是更换模型，也不是以预测分数取代精确分数。本功能仍不承诺枚举每一种同分身份排列，保持原求解器的代表队伍及助战／位置最优覆盖语义。

## 队伍对比

导航新增独立“队伍对比”入口。推荐列表中每支可见队伍均有“加入对比”，不必先覆盖当前编辑队伍。加入时按物理编成去重，并保留推荐列表。

对比页支持新建、复制、改名、移除、清空、单独编辑和设为当前队伍。编辑支持从者、灵基／灵衣、礼装、满破、上场／空位、助战、交换站位及适用的冠位额外礼装。自由模式可调羁绊；账号模式使用账号真实羁绊。

全部队伍在同一当前关卡、基础羁绊、活动和茶壶条件下实时重算。表格列出总羁绊、COST、逐位成员／形态、礼装、羁绊、加成及对其他队员的贡献，差异高亮。

编辑过程中允许保留未完成队伍，并提示人数不足、重复身份、账号未持有／形态未解锁、礼装及满破数量、COST、从者筛选、职阶、锁定位置、助战和已识别的关卡限制。存在提示的队伍仍可继续修改，但不能直接设为当前队伍。未支持的关卡限制会明确显示无法确认，避免宣称已经校验。

复制和编辑使用独立物理快照，不修改来源队伍和推荐结果。仅保存用户选中的六个位置及名称，随账号／区服设置恢复，不保存图鉴、候选池、等效身份数组或 DP 状态；未增加逐候选日志。多页布局中，对比内容仅在打开对应页面时计算与渲染。
