# 停止计算后保留已有配队

保留当前等效合并和精确搜索，不加入旧算法自动切换。

- 点击停止后，计算进程先保存已得到的方案，再返回结果；已有配队仍可查看、分页、切换类别和导出。
- 如果目前只有一套已验证的可行起点，也保留在队伍列表中，并标记尚未登记为合并方案组。导出文件头保留该可行队伍，不将其冒充完整方案组。
- 若停止时尚无可展示队伍，明确提示“尚未计算出可展示的合法配队；这不表示当前条件无解”。
- 不完整结果明确说明“当前最高分尚未证明为全局最优，全部同分方案尚未收齐”。只有完整搜索结束后才显示完成。
- 停止后翻页仍保留停止状态，导出文件保留 complete:false、maximumProven:false 和 stopped:true。

修复了首次结果之前硬终止、可行起点对应空 plans 列表、尚无最高分时空分页误报更新冲突，以及刚找到更高分时停止丢失预览等边界情况。快速停止并重新开始时，旧请求不能覆盖新查询。

验证包括 Worker 停止/启动竞争、起点预览及导出、完整/不完整状态标签、1,000 组独立穷举，以及真实应用的提前停止与分页导出检查。浏览器检查由 CI 的 stopped-results-ui 单独执行；对应产物包含 browser.json 和截图。
