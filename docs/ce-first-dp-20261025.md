# 礼装优先与从者 DP 证明快路径（2026-10-25）

本次在既有两阶段搜索中加入礼装优先的最高分证明引擎。全部最优并列队伍仍由原完整枚举器收集，没有候选数量截断；小问题和暂不可分离的问题继续使用原算法。

算法思路参考 Chaldea 的[设计说明](https://github.com/chaldea-center/chaldea/blob/e656fa4b3e23228805efdec851358e0ab319aeeb/lib/app/modules/bond/solver/design.md)，这里按本项目的实际库存、自动冠位候选、15 绊光环、目标函数及完整同分要求独立实现。

## 搜索与证明

1. 按实际 COST、逐接收者效果向量和固定值合并礼装，保留全部物理副本及满破状态。枚举普通礼装多重集、免费的冠位奖励位与助战组合，共同扣除普通位／奖励位占用的自有库存。未固定的零收益礼装与羁绊位在证明阶段可留空，收集阶段全部恢复。
2. 对完整且库存可行的礼装组合做支配比较：若另一组合 COST 不高、普通礼装需要的位置不多，且对每个接收者的比例／固定值都不低，则前者足以证明同一最高值。比较完整组合，不假定存在额外的可替换礼装副本。
3. 固定组合后，按从者 ID 做 0/1 DP：`dp[已占用位置 mask][COST][已用光环量]`。先枚举最终光环总量，再以“总光环－该从者自己的光环”计算其收益；最终只接受实际光环总量相符的状态。这样允许自由选择满羁绊光环提供者，同时保留其零收益或非零收益状态。
4. 每个位置、相同 COST 和光环贡献量，只保留最高的前 F 个不同可选 ID（F 为最多己方位置数），必选 ID 另行保留。其他位置最多占用 F−1 个 ID，故总能找到一个不差且未用的替代者；保留相同光环量保证替换不改变其他成员收益。同 ID 的不同形态共用一次选择机会。这个缩减仅用于最高分证明。
5. 礼装组合按安全上界排序。上界放松 COST 与共享身份，但保留光环提供者占用的位置数；优先从者目标另以“每个优先身份只能贡献一次”形成第二个上界，取两者较小值。最终 DP 见证还要通过现有精确结算，分数或合法性不一致时回退，不发布证明。

同职阶多个账号冠位仍是候选资格；自动冠位、固定冠位位置及前后排助战布局都进入证明。普通和奖励礼装分开计 COST、共享库存。小数层向下取整、茶壶、优先目标和大整数精度继续使用原有精确运算。

## 完整同分与停止

DP 的最佳具体队伍只作为预览更新最高已知值，不写入队伍档案。原因是后续完整收集器可能用一个等价方案组包含该队伍；同时归档会产生重复或混合两种结果单位。

证明结束后，完整收集器从根重新搜索，只剪去不能达到已证明最高分的分支。礼装 ID、满破、不同 COST、从者身份／形态及有效站位仍按原规则恢复；没有采用 Chaldea 的 20／100 个结果上限。停止发生在预览后、归档前时，仍能显示和导出真实可行队伍；停止在证明边界后则保留“最高分已证明、同分尚未收齐”。

所选 AI 最多推理一次，只用于等分候选及等上界组合的顺序。关闭 AI 为零次；没有更换权重或以预测分数剪枝。

## 适用范围与资源门槛

默认只对较大的普通／单冠位域尝试快路径：超过 12 个可选从者身份，或超过 4 个自有礼装物理副本，或超过 16 个助战礼装候选。小型条件礼装样本中，DP 准备成本高于旧证明轮，因此保留旧路径。

以下情况回退到原完整搜索，不删除候选或缩小规则范围：固定礼装、特殊关卡人数／NPC／多冠位规则、活动中的动态效果、自身或条件固定值礼装效果、负效果，以及无法安全处理的数值维度。对接收者的特性比例条件可以进入快路径。

临时数组与组合只在内存中存活，不写候选日志。当前门槛为 25,000 个组合、2,000 个非支配组合、2,000,000 个效果单元、250,000 个 DP 状态、12 个光环单位及有界支配比较工作量。超过门槛即从原搜索根继续，已有可行预览仍可用；这些门槛不等于全局搜索时限，也不会把未证明结果标成最高分。

内部审计开关 `scoreTeamAudit.ceFirst=false` 禁用快路径；`'force'` 仅让小规模独立测试也能覆盖新引擎，安全性和资源门槛仍生效。没有新增面向用户的算法设置。

## 同机三轮对照

同一代码和当前数据、相同输入哈希，在独立新 Node 进程中比较自动启用与禁用快路径。AI 关闭；每次搜索预算 5 秒，三轮交替顺序。基线取自同机未改动的禁用路径记录，最终代码重跑启用路径。计时从构造输入后开始，包括准备、预览复算和核心搜索；不包含 Worker 调度、磁盘归档及界面。

| 场景 | 原路径最高分证明 | 自动启用后的最高分证明 | 结果 |
| --- | ---: | ---: | --- |
| 全图鉴 Grand | 5 秒内未证明 | 362 ms | 42950，已证明 |
| Grand 优先从者 | 4693 ms | 290 ms | 15894，均已证明 |
| Grand 固定后排 | 5 秒内未证明 | 301 ms | 42381，已证明 |
| 全图鉴普通关卡 | 5 秒内未证明，暂定 7582 | 974 ms | 7593，已证明 |

优先从者样本的证明时间约缩短 16.2 倍。其余原路径未证明的项目只记录时限下界，不计算精确倍数。

小型条件 Grand 自动回退，完整搜索约 36.6／33.7 ms；活动场景回退后约 60.6／61.0 ms；特殊人数场景回退后约 423／447 ms。它们使用同一原算法，测量差异不能归因于 DP 提速。

**四个全图鉴样本的全部同分收集，在两种模式中都没有于 5 秒内完成。上述 362／290／301／974 ms 是最高分证明时间，不是收齐全部队伍的时间。** 已证明的具体预览可以先使用或停止后导出。普通关卡的 7593 高于原路径在时限内找到的 7582；没有据此改写原路径的未证明状态。

原始每轮结果、证明／完整状态、首个预览／归档时间、内存及实现哈希见 [benchmark.json](test-results/2026-10-25-ce-first/benchmark.json)。工作单位不同，不直接比较两引擎的节点计数；内存读数包含图鉴加载。

## 验证与复现

新增独立物理穷举对照 95 案例，176 次强制快路径证明（压缩开关两种模式），完整保留 43,749 套最优物理队伍。覆盖普通／Grand、共享礼装副本、满破、空位、形态与身份、必选／优先目标、光环、免费高 COST 奖励位和逐层取整；目录经 JSON 往返后展开。另检查默认小域回退与大域启用、7 类安全回退、三个模型各一次推理、预览与证明边界的停止／导出，以及证明队伍不会重复归档。

沿用的 Grand 105 案例仍保留 27,168 套最优物理队伍；1,000 组独立随机对照仍保留 232,234 套最优物理队伍。完整测试与 CI 状态见 [validation.json](test-results/2026-10-25-ce-first/validation.json) 及 PR 检查。真实浏览器的 Worker、OPFS、分页、停止、完整导出与恢复仍由 CI 验证。
