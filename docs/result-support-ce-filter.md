助战礼装筛选使用本次计算已经得到的配队集合，包括完整分页、最高分方案组、途中其他已得队伍和组内等效普通礼装，不从全礼装图鉴或可用礼装池添加选项。尚未收齐时，集合随已得结果更新，不代表尚未得到的礼装无解。

点击礼装只筛选现有结果，不重新启动查询或 AI。支持无普通礼装的实际结果；冠位报酬栏不计入普通栏。分别显示匹配的最高分组数和途中其他组数；仅出现在途中其他队伍里的礼装会打开该类别，原查询最高分与完整性标记保持不变。筛选、翻页、同分成员/礼装切换和当前选择导出保持一致，取消筛选恢复完整结果。完整 JSONL 导出始终包含全部已得配队。

Worker 在接收每个方案组时累计礼装与分数计数，组内选项读取无损等效目录，不展开全部物理组合；筛选按磁盘页读取，保留原档案位置与筛选后位置，翻页读取可让出事件循环。索引随当前查询释放，不复制账号或完整结果档案到 UI。

验证覆盖：135 个最高分结果跨页筛选、其他分数分类、等效礼装、独立物理枚举合法性、停止前已有结果、动态增量集合、磁盘/内存一致性、迟到回复、无额外查询、筛选后同分切换与当前队伍导出；真实浏览器断言仅发送一次求解请求，未出现的可用礼装不列入集合。
