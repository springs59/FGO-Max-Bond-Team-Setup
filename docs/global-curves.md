# 全局羁绊曲线检查版（2026-10-10）

本次的“全局”是指**已明确投影的普通编队理论图鉴范围**内，所有非负整数基础羁绊的全局最优，而不是选定某支队伍后比较礼装，或从若干基础羁绊点获得的候选队伍。

| 日服普通 | 470 | 2,969 | 131 | 236,934 |

活动投影采用 `2026-10-10T00:00:00Z` 和项目已有资料，在该投影下国服 32 个关卡共用一个加成向量，日服没有额外的有效活动向量。活动是否适用由关卡、记录时间、目标身份等规则决定，不将历史活动奖励混入普通曲线。

同时覆盖无助战的最多六位己方、前排或后排助战的最多五位己方。允许空位；从者身份不重复，同一身份的形态互斥。每种资料礼装一份，同效果不同礼装保留数量。肖像上限可以 0–6，助战肖像独立于己方上限；检查页默认枚举 0–6 张，肖像完全可选，账号只有一张时设上限为 1。每种未满破效果也存在于原始资料；在自由持有范围、相同 COST 下，同一张满破礼装逐人不劣，可安全替代其未满破状态。

覆盖所有 0–168 COST 条件、空装至满装、20% 限定礼装的实际逐人命中与交叠、无限定百分比、固定肖像叠加、0–5 位满级 15 绊光环成员和活动自身／全队加成。满级成员可携带礼装，但其羁绊为零。COST 168 已覆盖六位最高 16 COST 从者和六张最高 12 COST 的范围。

这是理论图鉴持有范围。具体账号的持有、礼装份数／满破份数、满级身份、锁定位置等条件必须**先投影，再运行展开和求解**，不能直接过滤这个全局最优库。图中 15 绊成员可从全部身份中选择，也不是账号既有满级身份的证明。本次检查版不包含冠位及其奖励槽、战斗可行性、锁定条件和已结束活动。全员满级、无人领取的零收益方案不可能改善最优值，未列入可领取曲线。线上版本尚未接入。

## 检查页交互

- 默认不指定从者组合。COST 默认 113；肖像 0–6 张、满绊光环 0–5 人、三种编队和全部助战礼装效果一起比较。图中默认显示所选 B 范围内参与上包络的全部组合函数，取消原先 16 条限制。
- 每条曲线都有完整下拉说明：礼装类型和名称、每张命中己方上场／可领取人数、助战位置及礼装、成员形态、佩戴示例、空装和空位、COST、逐人双层取整函数与总函数。己方佩戴数不能超过己方实际人数，助战礼装独立至多一张。
- 优势区间使用严格内容键合并：函数、COST、礼装、助战和代表成员都相同才合并。重叠或相邻区间合成一段，非相邻区间收进同一下拉项。仅羁绊数值相同的不同配置不会合并。
- “全部计算结果”逐页展开所有礼装多重集及各自的可用函数，包含被其他礼装组合支配而未进入最优库的结果，空装也会显示。每页 30 条，可继续到遍历结束、搜索、加入图中和停止展开；不是 Top N。函数数量随条件变化，展开结束前只显示实际扫描数，不编造总数。
- 全部结果沿用效果向量和 COST 支配压缩：等价从者取代表，同效果礼装每个数量取最低 COST 前缀；同一礼装多重集内已证明逐人不优且 COST 不低的队伍不展开。不是所有从者身份、相同效果礼装身份和佩戴顺序的字面排列清单。
- 用户可选定最多六名己方身份。选定身份先从完整原始形态資料投影，每个效果向量保留全部选定身份，再保留六个其他最低 COST 的不同身份；身份 DP 对选定者禁止跳过，并保留其可领取和满绊状态。这保证不是按旧曲线代表队伍名称过滤。后台 Worker 重算完成前显示进度，变更条件会取消旧 Worker。
- 选定身份只要求必上场，未锁定形态或位置。具体账号的已满级身份、持有范围和礼装库存仍需另行完整投影。普通助战身份不影响函数，同效果助战礼装展示一个具体代表和完整替换名称。

## 完整性依据

1. 先保存原始身份、形态和礼装效果。只有完整效果向量、活动自身／光环相同的形态可合并；每向量保留六个最低 COST 的不同身份，身份仍由 DP 逐一处理。至多另有五个身份已占用，所以被删去的身份总存在等效、成本不更高的可替代者。
2. 全队普通礼装的佩戴顺序不改变效果，因此枚举礼装多重集即可。计数包含空装，依照实际不同礼装数量限制；等效礼装每个数量保留最低 COST 前缀。限定加成累计到每个真实形态，不以“命中人数”替代交叠关系。
3. 对每个累计礼装向量，身份 DP 保存未满级第二层系数的有序多重集、满级人数、全队活动光环以及最低 COST。只在这些条件相同、逐人系数均不低且 COST 不高时删除方案。每个身份只能选一个形态和一个满级状态。
4. 展开所有合法前后排分配。固定肖像上限、助战礼装效果、满级人数等条件下，只删除逐位置系数不低、COST 不高的支配曲线。额外正系数成员可以替代空位。这样的支配在每个整数基础羁绊下都成立，与取整无关。
5. 每个未满级成员的函数是 `floor(floor(B*f/1000)*s/1000)+flat`。统一周期 `T` 使两个乘积增量皆为整数，故 `F(q*T+r)=q*Δ+F(r)`。对每个余数，建立关于整数 `q>=0` 的精确直线上包络，交点用整数及 COST 平局规则计算。国服公共周期至多 1000，日服含 2% 礼装时至多 5000。
6. 为提高包络速度，用可行曲线的取整误差下界和候选曲线的连续上界确定可能胜出的 B 区间。只删除已有不等式证明永远输掉的余数；不是抽样或 Top N。检查页的显示范围不限制最优性证明范围。

同函数同 COST 或并列最优组合给一个代表，原始资料和生成程序可还原其他等价组合。216 组常用条件的 0–2000 整数优势区间另附 CSV/JSON；检查页可自由输入其他 COST 和更大的基础羁绊。

- 原有及新增的全部 54 个测试文件逐一执行通过。

## 复现

需要 Node.js、Python 3、g++。在本仓库根目录：

```bash
node src/solver/global-curve-expand.test.js
node src/solver/global-envelope.test.js
node scripts/global-curves/run.mjs /absolute/output/directory
```

`run.mjs` 固定使用本次日期和项目资料，先完成导出及原生编译，再逐场景计算，最后生成并校验检查页。原始礼装／形态必须完整投影后才进行支配删除；不能将检查页的图鉴全局结果当作任意账号的完整索引。
