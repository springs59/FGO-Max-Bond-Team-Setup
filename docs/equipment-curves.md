# 礼装组合、肖像与跨基础羁绊的比较

## 本次修复

英灵肖像的固定 +50 是全队羁绊奖励：每张同时给所有可获得羁绊的己方成员增加 50。自出与助战携带的肖像相互叠加；已满羁绊的成员可以携带肖像给其他成员加成，但自己不获得羁绊。重新计算、移除礼装后清除旧的固定奖励。

快路径、通用礼装搜索、搜索上界、独立结算校验和预计算使用相同的奖励范围。快路径比较助战的百分比和固定加值；上界根据实际礼装固定值及可用装备位计算，避免将固定值写死为每人 50。大流士三世肖像的原始 buff 载体为 self，奖励范围按肖像系列（礼装编号 99—108）归一为全队。

## 无损组合数据与候选队伍的区别

`generated/combination-factors.json` 保存所有从者与灵基的身份、COST、特性，以及每张礼装在自出／助战、满破／未满破四种状态的百分比向量和固定加值向量。`ceEffects` 同时保存 COST、目标范围和条件原文。相同效果可以共享向量，身份、满破状态和库存条件仍然保留。

这个基数无关的组合表达包括 0 到装备位上限的数量选择、不同条件礼装的重叠命中、无条件礼装、多个肖像、空位、不同从者状态及活动效果。它是组合的压缩表达，**不是已经展开并列出每个具体队伍的结果表**。实际账号、锁定条件、特殊系统助战、Grand 和无羁绊效果的强制装备仍通过查询条件或通用求解器处理。

`solution-index.json` 是默认查询的结果缓存，`curve-index.json` 是候选曲线缓存。它们都不等于全部队伍表，不可以在账号或 COST 筛选后仅从它们挑一队并声称最优。当前受支持的查询仍需完整展开或精确搜索。

## 函数

令 B 为非负整数基础羁绊，i 为可获得羁绊的己方成员：

```
F(B) = 茶壶倍率 × Σ_i [ floor(floor(B × front_i / 1000) × second_i / 1000) + fixed_i ]
```

`front_i` 包含前排与前排助战的第一层倍率；`second_i` 包含命中该成员的礼装、活动自身加成、队伍光环和有效 15 绊光环；`fixed_i` 为所有命中该成员的固定奖励之和。助战本人、空位和满羁绊成员不作为收益项。

不可仅按礼装百分比总和排序：20% 只命中部分成员，可能不如命中全员的较低百分比；肖像是截距，低 B 下可能胜过百分比礼装。不同前后排、活动加成、人数、COST 和命中范围下，交点不同。保留两次向下取整后，优势区间还可能在邻近整数之间交替，不能用一次连续直线交点代表全部整数结果。

## 页面曲线入口

推荐结果下的“比较此队伍的礼装全组合曲线”固定当前从者、灵基、前后排、活动被动及羁绊状态，在当前库存、满破状态、禁用礼装、助战礼装和 COST 条件下展开所有普通全队礼装组合。没有预设候选数量上限，也不会因在原基数表现较差而删除一个组合。

枚举后按每个整数 B 精确比较，绘制区间内获胜的方案；用户可改变 B 区间并显隐曲线。同收益优先较低 COST。等效礼装只在库存与约束已经确定后合并，保留可装备数量与真实持有代表；这不会改变固定队伍的最高收益。

**图表证明的范围是固定当前队伍的礼装选择，不是所有从者队伍的全局包络。** 改变从者、位置、关卡规则或账号后需重算。Grand、佩戴者专属效果及锁定礼装的完整位置展开交给通用求解器，图表不将这些条件误标为已覆盖。

## 验证

新增独立逐位置穷举，对照多张肖像、助战肖像、未满破、条件命中／未命中、满羁绊携带者、空礼装和多个 COST 上限。预计算生成后，曲线索引继续以独立结算器跨多个基础羁绊及茶壶状态核验。
