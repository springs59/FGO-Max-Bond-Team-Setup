## 保存与恢复行为

候选与物理方案保持原内容与校验格式。准备物理方案时限制为每批 128 条，并用原子事务更新；新增事实用主键 add 自动拒绝重复，只有重复主键错误被处理，配额或磁盘错误仍回滚整个当前批次。归档消费每批最多 512 条、1 MiB，不增加计算阶段固定 256 KiB 写缓冲或 64 KiB 传输上限。

数学结果先与封闭日志的名称、记录数、字节数及校验和一起暂存。暂存数据不能成为完整条件缓存，也不会出现在库列表或备份中。全部日志消费成功后，核对完整记录数和字节数并原子提交缓存，再删除日志。搜索未完成、日志仅恢复部分或核对失败均不会被标记为完整最优答案。

实际生产 Worker 专项测试在结果显示后、入库前暂停并立即终止 Worker：活动日志未被恢复程序抢占，终止后全部 664 条候选恢复，数学总收益 7956 保留；另一账号再次查询精确命中，搜索节点为 0，不重做已完成的搜索。记录数不匹配不能提升为完整缓存、重复恢复不重复导入、写入配额错误的事务回滚也通过。

实际应用界面显示已算完的 7956 和“停止保存”，显示“正在保存全部已计算候选”。此时点击完整库导出，原生写文件入口在保存前不会启动，保存结束后成功导出。界面无未捕获错误。导出仍是整个聚合库的一个未压缩 JSONL 文件，不出现选择导出内容步骤。

## 本版本真实存储负载验证

本版本实际运行约 182.8 秒，非虚拟时钟；317 次完整查询、139273 条候选及曲线核对、41549824 次独立结算核对。归档 138375 条、201986260 字节，最后日志 898 条，满足 `139273 = 138375 + 898`。缓冲峰值 262143 字节，未超过 256 KiB。终止后恢复最后 898 条，重复恢复不重复处理；跨账号完整条件缓存命中，收益 6766 一致。

去重后的库为 57840 条，导出单个未压缩 JSONL 为 114736221 字节、57841 行；SHA-256 为 `e02a0be30659b5889855b656a62258b76c104202d26de74574173dadcf8608c6`。整个浏览器进程树 RSS 峰值约 781.8 MiB，相对预热后的增长约 21.2 MiB；不是仅测 JavaScript 堆，也未强制 GC。

这是新增保存行为的三分钟真实负载和专项中断验证。本版本没有重跑两小时耐久测试；[2.0.5 的 125 分钟记录](verification-2.0.5.md) 属于上一版，不能当作本版本已跑两小时。运行没有增加两小时或其他固定等待上限。全量候选保留、跨账号通用方案、单文件迁移合并及软件内更新继续保留。
