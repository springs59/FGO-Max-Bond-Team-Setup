# 已核实 AI 下界优化

基线为 2.1.2 发布后的同代码数据快照 `13d8fa7ed273c0f86c2babd9b2b6bc9c78767519`。本次在独立分支 `feat/verified-ai-lower-bound` 验证，不恢复预计算扩仓，不训练或更换模型。

## 改动

普通礼装向量 / 身份 / COST DP 在 AI 启用时，为初始礼装组合预留组成合法队伍所必需的最低 COST。按身份取已允许形态的最低成本，计入所有必选身份，再用最便宜的其他身份补足最低上场人数和当前礼装数量。这里放松位置、光环和评分约束，因此得到的成本只可能比真实合法编队更低，不会高估必需成本。

保留原有两个模型起点中所有未被此成本界限证明不可能的起点；只有被证明不可能成队的起点才由预算内的新提议替换。仍最多精算两次。每次提议都经过原精确身份、位置、库存、光环和羁绊取整求解，分数才可成为下界。不会把模型分数或未核实的预测当作截止值。

正式搜索再次到达已经精算的相同礼装列表时，复用这次查询内已经处理的结果。最多保留两个长度不超过编队容量的引用数组。初始核实覆盖同一查询的所有请求助战 / 位置 / 光环子问题；当时因数学上界被剪去的子问题，在更高或相等的后续下界下仍可安全跳过。没有额外的逐候选日志或全状态缓存。

搜索节点同时使用必需从者成本界限，提前拒绝“礼装还没超预算，但已无钱组成最低合法队伍”的分支。羁绊分数剪枝仍严格使用 `上界 < 已核实下界`，保留同分及更低 COST 的搜索机会；需要保留多个助战/位置最优结果时继续使用原有各分支界限。

AI 关闭或模型无效时，不构建上述成本表、不执行模型起点复用，沿用原搜索。未改变复杂枚举路径和主练优先规则；本次优化的范围是普通向量 DP。模型协议、权重和用户 AI 开关保持现有版本。AI 开启的搜索缓存身份增加策略修订号，关闭状态的缓存身份保持不变。

## 诊断

结果增加初始可行下界、下界剪枝和起点复用次数。计算中显示起点下界。核心证据中的分数为未乘茶壶的数值；推荐页面按本次查询的茶壶系数转换，不能按用户之后的界面状态重新解释旧结果。

## 验证入口

```sh
npm ci
npm test
FGO_LB_BASELINE=/path/to/unchanged-2.1.2 FGO_LB_CASES=64 FGO_LB_ROUNDS=5 FGO_LB_OFFSET=5400000 FGO_LB_PUBLIC=1 node scripts/check-ai-lower-bound.mjs
node scripts/summarize-ai-lower-bound.mjs docs/test-results/ai-lower-bound.json docs/test-results/ai-lower-bound-summary.json
```

独立 Node Worker 交替运行旧版和候选版，排除事先声明的一轮预热；计时仅覆盖求解核心，不含界面、数据传输和持久化。每轮比较最优分数、COST 同分结果、保留的助战/位置分支，并检查初始下界不低于旧版。32 个开发条件使用过种子 4600000 起；独立确认使用 5400000 起及预先指定的公开图鉴条件，不以开发性能代替确认结果。

额外约束回归覆盖 42 组必选身份、多个形态、固定位置、空位、最低人数、不同 COST、零基数和全部助战/位置结果；已有 160 条 AI 对照与独立无剪枝参考继续运行。浏览器验证下界显示、用户开关、模型更新、缓存隔离及移动端布局。

性能结果以对应提交的 `AI verified lower-bound validation` 工作流和结果摘要为准。有限测试不能证明所有未来条件提速，也不证明所有同分身份排列被枚举；本次没有 APK 实机性能结论。

## 本地确认结果

源代码 `180ce5168baddc0b8574cf6dbbcea09d681343d8`，64 个独立确认条件，旧版与候选版各 5 次正式测量，另各有 1 次预先声明的预热。包含合成条件、公开图鉴子集和 30 / 120 / 240 / 完整图鉴；COST 随条件变化，含不限 COST。没有删除不利样本。

| 项目 | 旧版 | 优化版 |
| --- | ---: | ---: |
| 各条件中位耗时合计 | 3726.73 ms | 3322.64 ms |
| 可行条件的起点已达最优分数 | 23 / 49 | 26 / 49 |

本机求解核心合计减少约 10.84%；64 个条件中 49 个更快，并非逐条件全部提速。49 个可行条件中初始下界提高 7 个、相同 42 个、降低 0 个。所有正式轮次的最优分数、COST 同分目标和保留助战/位置结果相同。一次代表性求解统计合计复用精算起点 80 次、由必要编队 COST 界限剪枝 498 次。

配对查询中位数合计比值的 10,000 次 bootstrap 95% 区间为 0.692–0.946，只描述此测试条件集的变化，不代表所有设备或未来条件。原始各轮耗时与逐条件证据见 [本地确认摘要](test-results/ai-lower-bound-summary.json)。下界剪枝计数包括搜索过程中所有已核实可行解的作用，不能全部归因于 AI 初始方案。
