# 2.1.6 三个可选 AI

在配队页面底部展开“AI 辅助与模型更新”，使用“AI 模式”选择框。默认“不使用 AI”，选择会保存到本机，下次新查询生效。

|选项|功能特点|
|---|---|
|不使用 AI|直接由精确求解器计算，不调用模型。|
|经典高起点 AI（H）|原有高起点方案，在未见组合测试中表现较稳；启用AI时建议优先选择。|
|扩展策略 AI（T）|改进的单教师决策树，从更丰富的固定策略中选择起点。|
|大数据神经 AI（N8192）|以8192条配队条件训练的普通网络，公开图鉴测试中起点质量较高，未见组合可能退化。|

三份模型内置在软件中，无需联网下载或分别安装。没有自动选模型、在线轮跑比较或第二次模型调用。每次新查询最多一次树决策或网络前向，后续复用固定策略；结果缓存命中为零次。合法起点和安全范围经过精确规则核实，最终结果由精确搜索确定。模型不能凭预测值删除可能最优的分支。

“经典高起点”是启用AI时的建议，并非默认自动开启。旧版明确的开关设置会迁移；已不提供或损坏的旧模型设置回到不使用AI。模式和模型以一条存储记录保存，保存失败只对本次会话生效，不会把旧的关闭状态意外改为开启。

软件内更新或恢复模型不会更改AI模式；没有查询策略的旧逐候选模型被拒绝，保留内置模型。三个模型的结果缓存互相隔离。

此前同批54普通条件中，T/N8192相对H耗时合计下降7.46%/4.66%，固定代表复测却增加6.83%/1.08%，没有稳定普遍加速证据。起点质量不等于最终求解速度。完整历史结果见[测试日志](test-results/2026-10-20-ai/README.md)。

## 推理方式复核（2026-10-21）

已按训练用途分别比较整查询单次、特征子域变化时重新推理；并把原框架双神经头的逐候选与评分去重另列参考。62 条件、9 组配置的结果未提供足够稳定的证据，支持默认改变现有三款的原生单次方式。固定助战礼装差异组中，分域版确实推理 3 次，但独立复核未见稳定提速。原框架不是 T 模型，也没有作为第四选项加入软件。

完整方法、耗时、推理次数、58 个普通条件与 4 类压力观察的完成/未完成记录见 [按模型用途验证推理方式](test-results/2026-10-21-inference-modes/README.md)。

## 取消单次约束后的参与方式探索（2026-10-21）

上文“每次最多一次”描述的是正式版 2.1.6 的当前实现，不是模型只能这样使用的技术限制，也不是本轮验证的前提。上一轮只比较整查询、子域复用及候选去重，覆盖范围不足以确定各模型最适合的用法。

后续已放开调用次数，比较 20 个 AI 配置，包括多预算起点、神经 Top-K、剩余条件重推、停滞重推及组合方式，并分别保留原生对照。模式按校准数据冻结，随后进行独立核心盲测、完整 Worker 留出和压力观察。具体候选、调用次数、耗时与局限见[不固定次数的参与方式探索](test-results/2026-10-21-adaptive-inference/README.md)。研究变体未替换正式版运行逻辑。
