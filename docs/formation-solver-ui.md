# 配队求解器与曲线界面

主界面右上角“配队求解器与曲线”打开软件内的完整检查界面，Windows、Android 与网页使用同一份代码。

- 编队条件：按己方、助战及前排助战人数联动，提供基本、无助战、冠位及已解析的特殊人数规则。无助战至多自出六人，允许少上与空位。
- 活动效果：当前条件的有效活动分档、自定义匿名分档，与礼装命中分布联合比较；不同活动不混用对象数，历史活动不自动生效。
- 曲线检查：完整匿名结果逐页展开、添加比较线、显示两层取整函数与优势区间，按实际资料和指定身份精确核实。首次计算由用户点击开始，可停止。不会把匿名上限标为实际可实现值。

界面使用打开时主界面加载的同一份双区服数据；软件已经加载的数据来自本机已提交的数据快照时，曲线界面也使用这份数据。后台数据更新生成完整身份/形态的曲线资料域，打开界面优先读取本机资料域与礼装命中向量。构建仅打包代码，不做联合计算。

匿名曲线和精确核实结果保存在本机 IndexedDB。再次打开或重复求解相同条件时优先复用；缓存键包含完整身份、形态、礼装效果、活动、编队规则和所选参数。基础羁绊作为变量在查询时结算，不按基数重复生成。数据版本、区服、规则或活动有效边界变化后不得复用旧域。后台正在发布新数据时，已打开界面继续使用完整的原快照；重新打开会根据主界面加载的数据校验。

本页实际核实的范围是自由图鉴持有、每种礼装至多一份且满破。账号库存份数、未满破、实际满绊身份、锁定位置和战斗条件仍使用主界面的账号求解器，并独立缓存。打开时显示当前账号及该范围说明。冠位是资格满足后的规则模板，不表示区服开放或账号解锁。

当前快照不能完整解释的固定系统助战、多人客将或强制衣装规则明确列入未支持统计，并提示转主界面按关卡规则求解，不能放宽成普通好友分支。新增礼装机制若超出曲线模型，检查界面报出对应礼装；这个辅助界面的规则不足不会阻止主数据与账号预计算更新。

验证：域构建与本地因子逐项一致；身份/形态完整；无助战容量、特殊人数、实际活动加成与独立结算一致；区服/版本/规则/活动边界失效。浏览器检查三页联动、非法活动人数、完整曲线和逐页结果、精确核实、基数变化、本地持久复用及320–1440px布局。
