# 推荐状态、同分成员与队伍档案

推荐结果导航原先只用 `recommend.ok` 显示“已完成”。现在导航和详情使用同一套状态：寻找合法队伍、证明最高分、最高分已证明但补全同分中、全部完成、停止后的部分结果。结果区逐项显示合法见证、最高分证明和同分收集，保留真实节点/完整组合/剪枝/耗时；不虚构百分比。停止前的已证明最高分与未收齐同分继续分别标记。

“换一套同分的不同从者组合”按己方从者 ID 集合区分，不把站位互换计作新成员组合。组内从者池按组合惰性展开，保留实际 CE 与其角色；若当前装备下的单人替换同分但不属于全局 CE 等效池，再逐一精确结算并核对 COST、必选/钉住/固定成员、冠位身份和羁绊礼装归属。特殊关卡约束与 NPC 不用这个额外邻域回退。当前组及邻域没有另一种成员时会提示；这不声称其他尚未收齐的方案组没有不同队伍。它不修改全局最优证明、统计或完整归档，不调用 AI，也不是以邻域代替完整搜索。

助战筛选原先从当前结果页提取普通 CE，所以只显示该页出现的卡。现在从当前筛选条件下的助战羁绊 CE 候选域展示完整列表，可按名称/ID 查找；未在当前页出现的 CE 不标无解，已见分数不冒充该约束的独立最高分。点击普通 CE 重新精确查询，重复点击解除；正在收集时可直接切换查询。固定剧情助战不开放更换；冠位报酬栏与普通栏明确区分。

## 导出与重看

- 推荐结果、当前队伍和全部对比队伍均有导出入口。单队 PNG、多队单文件 PDF、可编辑 DOCX 表格、JSON 数据以及含内嵌配队图与数据的单文件 HTML。不提供 ZIP 下载，也不依赖运行时 CDN。
- HTML 可直接离线打开；HTML/JSON 可用页头“打开队伍档案”查看当时条件、成员、灵基、普通/羁绊/报酬 CE、满破、逐位收益、总分与 COST，不启动搜索。导出标明保存时的最优证明与同分完整性；自选/编辑队伍不继承推荐的全局最优标签。
- PNG 一次一队。多队 PDF 每队一页，使用图像页保存中文与图片的实际布局；PDF 文字不作为可搜索文本。DOCX 使用可编辑表格，当前不嵌入立绘。
- 图片跨域或离线失败时保留名称、形态、CE 角色与满破信息。图片请求只在导出时开始，共享缓存并设总超时，结束释放位图。不改变求解热路径。
- 全部已得到的方案仍用完整 JSONL 导出，不用当前页或报告代替全量结果，不限制方案组数。JSONL 保留等效目录和约束，导入后按 64 组顺序读取全部实际代表队伍；显示保存时分数，不重新求解或把部分结果说成完整。
- 导出格式选择保留在本次页面会话中，避免图鉴异步加载/进度刷新把已选择的格式重置成 HTML。
