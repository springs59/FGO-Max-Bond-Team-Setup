# 队伍对比立绘与条件羁绊复核

队伍对比表的“从者／形态”行增加当前所选从者的图片、形态文字及冠位标记。编辑区同步显示当前从者与普通、羁绊、报酬礼装，礼装分别注明位置类型和满破状态。空位和无从者身份的好友助战不显示错误角色图片。

图片优先使用当前再临／灵衣对应的立绘，缺少立绘时使用同形态头像；缺失灵衣图片不会用其他灵衣或默认再临冒充。图片异步加载并复用既有图鉴请求缓存，不参与精确结算，不把图片资源写入方案或账号快照。换人、切换灵基、切换区服或收起页面后，旧请求不能覆盖新选择；离线或所有地址失败时保留名称与形态文字。

本轮同时补充一个完全合成的羁绊回归场景：条件礼装要求“秩序 AND 女性”，不能只因从者是女性就算命中。以 B=4748 的前排为例，错误多算 20% 时，11109 与 9969 相差 1140。测试分别覆盖混沌女性与秩序女性、不同的第二种条件礼装、身份变化后重建特性、比较时忽略旧缓存总分，以及固定物理队伍的完整精确最高分与同分收集。测试不包含账号抓包、账户库存、原始截图或导入结果。

验证：

- `node src/ui/comparison-art.test.js`：选中再临／灵衣、普通／报酬礼装满破标识、名字转义、同从者请求去重、离线及迟到请求隔离。
- `node src/ui/comparison-workspace.test.js` 和 `node src/party-state.test.js`：编辑、复制、条件重算、账号约束和紧凑保存。
- `node src/solver/conditional-female-score.test.js`：独立固定规则下的逐位结算、1140 分差异和完整固定队伍搜索。
- `scripts/check-team-comparison-ui.mjs`：实际应用中加载可解码图片、换人及灵基后图片同步、礼装位与满破显示、复制不影响原队伍、320／390／834／1440 宽度的页面布局。图鉴和图片使用确定的公共合成夹具，不依赖外站在线状态。

本改动不变更当前羁绊公式、求解器上界、模型权重、查询推理次数或发布请求。
