# 精确求解的分数区间约束

代码提交：`a81732dce6cc0e85d59de9ee2dced0cdff639152`。比较基线为第一轮已核实起点优化 `c5476ee95e517e03719f1943190483149bb45464`，不是原始 2.1.2。本轮在同一独立分支验证，不合入 main、不发布安装包、不恢复预计算扩仓，不训练或更新模型。

## 下界是搜索域约束

AI 只提出初始组合。精确核实得到合法完整队伍后，其真实分数成为下界 L。每个 DP 中间状态计算所有可能补齐方式的安全上界 U(state)。只有 U(state) < L 时，才在状态扩展、队伍数组分配和支配性检查之前跳过。对于新产生的转移，同样先检查，再分配状态。可选身份的跳过路径也受到此约束。

部分队伍当前分数低于 L 并不表示它无效，后续成员、位置和 buff 可以提高最终得分。所约束的是完成后的分数。上界大于等于 L 的部分状态仍需继续精确求解。等号保留，以维持同分结果及更低 COST 的比较。

## 安全上界的构造与证明

固定礼装、助战、位置和总光环后，每个可选形态的前排/后排羁绊分数已经按原规则取整。对尚未处理的身份建立后缀 DP：每个身份允许跳过、占一个前排或占一个后排；多个形态取可达到的最大分数。保留身份不可重复和剩余位置容量，放松剩余 COST、必选身份、最低人数和总光环必须相等的限制。每个未满羁绊成员的固定加值也计入。

放松后的可行集合包含原问题所有合法补齐方式，因此其最大值不会小于真实补齐最大值。完整分数的状态上界为：当前已累积位置分数 + 当前有效人数 × 固定加值 + 后缀最大补齐分数。若它仍低于已核实合法队伍分数，则该状态不可能改善或追平该队伍，跳过不会损失所需的最优结果。

后缀数组为 O(身份数 × 前排容量 × 后排容量)，不枚举队伍身份子集。容量最多 6，数组只在本次求解内存在，不写入临时方案文件。AI 关闭或无合法下界时不建立后缀表。缓存策略修订号由 2 升为 3，关闭状态的缓存身份不变。

多个助战/位置结果需要分别保留各自的 L，不能用全局最高分删除较低的其他分支。为兼容现有返回值，本轮内层 DP 始终使用该分支已核实分数；现有外层搜索仍使用原来的全局或分支截止规则。动态更好的可行解会提高后续子问题的下界。

初始全局安全上界复用原礼装搜索根节点的数学上界：放松礼装数量分配、预算等约束，保留分数规则。它可能比真实最优值宽得多，不称为提前求出的真实最大值。完整精确搜索结束后，全局最优分数同时给出最终上下界，即 L = U = 最优值。

## 显示和验证

结果显示初始可行下界、初始安全上界和 DP 状态跳过次数。茶壶开启时两端分数同步乘二。状态跳过计数包括被拒绝的状态/转移尝试，不是唯一队伍数量，不能当作仓库方案数。原有下界剪枝计数仍表示外层分支剪枝。

完整 `npm test` 已通过。增加后缀上界与独立穷举的逐格比较，覆盖可选人数、形态、前后排限制、负的部分奖励、固定加值和满羁绊成员；42 组约束比较及已有 160 条 AI 对照、独立无剪枝参考继续通过。

本地独立确认使用 64 个条件，各版本 5 轮正式测量，事先排除各 1 轮预热，交替运行独立 Node Worker。条件含合成、多形态/特性、公开图鉴子集及完整图鉴，COST 随条件变化并含无限制。每轮最优分数、同分 COST 和返回的助战/位置目标均一致。另有 32 个开发条件，不计入下面的确认数字。

64 个确认条件的各条件中位耗时合计，从 862.21 ms 降至 530.69 ms，减少 38.45%。其中 32 个更快、32 个更慢，逐条件耗时比中位数为 1.006；收益集中在部分 DP 状态较多的条件，不能解释为每次查询均提速。47 个可行条件初始下界完全相同，说明本轮收益来自搜索域剪枝而非更高的初始起点。每个条件取一轮确定性统计，合计跳过 281150 次 DP 状态/转移尝试。见 [本地确认摘要](test-results/ai-interval-summary.json)。

上述本地正式计时在完整回归结束后独立运行。求解核心计时不含 UI、传输、数据加载或 IndexedDB，不代表 Android 实机耗时。配对查询中位数合计比值的 bootstrap 95% 区间为 0.465–0.877，仅描述此批条件；无不利样本删除。

另一批 32 个新条件开启全部助战/位置最优结果，各版本 3 轮，全部目标逐轮一致。各条件中位耗时合计 11279.85 ms → 1845.14 ms，减少 83.64%，21 / 32 个条件更快；合计跳过 2387312 次状态/转移尝试。该批包含特别耗时的基线条件，不能将这一比例视为一般查询预期。见 [全部分支确认摘要](test-results/ai-interval-alternatives-summary.json)。
