# 原框架版并入 main

本次合并用户指定的 `977d6f8`，基于 `ecd8ff4` 的 main。运行时代码保持该
基准提交的原始内容；额外把 48 组框架开关对照登记到 `npm test`。

该版本使用 AI 提出初始队伍框架，经实际规则、COST、人数、位置、光环与整数
结算验证后才作为可行下界。分支只能由安全数学上界严格小于下界时删除；
相等分数仍继续搜索，以保留同分最小 COST 和要求的助战效果/位置代表。
未按模型概率直接删除固定比例的队伍，也未重训模型权重。

保留现有 AI 选择开关。AI 关闭、小查询与完整候选回调继续原兼容内核；
不会强制开启 AI。计算期间不增加队伍日志、临时结果文件或完整候选树缓存。

## 与六项实验的区别

本次不合入 `perf/framework-six-rebuilt` 后续六项实验：效果准备缓存、紧凑身份
DP、数值前沿、等效礼装子问题缓存、规模策略和 WASM。该实验在同一批小样本
中的条件中位数合计反而增加 13.75%，账号完整推荐增加 37.24%，不作为 main
的默认实现。实验分支独立保留，未来可继续研究。

## 验证范围

此前 13 条件、5 版本、每条件 3 次正式重复的固定输入对照中，原框架的最终
得分、同分 COST 与请求的助战位置代表目标一致。计时波动较大，不能推广成
所有查询的固定加速倍数。

本次合并执行 `npm test`、`npm run validate-data`，并另外运行
`node scripts/verify-rebuilt-framework.mjs` 复核三条历史诊断记录及 48 组开关
对照。新增自动测试不固定公共游戏数据的期望分数，避免新数据发布时仅因
正常数据变化误报失败。

该框架是根据实现记录重建的版本；原 `f91b26f` 未恢复，不能声称与其文件
哈希相同。详细来源见 `rebuilt-framework-provenance.md`。
