# 未指定冠位位置时搜索全部合法己方位置

基于 main `a2b21a36e980c157eae004263b8799dc4f1e6b5d`（软件 2.1.21）。

## 问题与行为

账号有两名冠位分别固定在 4、5 号位时，自动位置关联因候选不唯一而保留“不限”。旧搜索却把“不限”解释为只允许 1–3 号位，导致零节点无解；手动选择 4 号位则有合法队伍。

现在未指定冠位位置时，物理枚举、礼装优先的最高分证明和特殊编成枚举都搜索所有合法己方位置（1–6 号位）。助战与固定 NPC 占据的位置、锁定空位仍不能作为己方冠位位置。关卡明确的冠位启用位置继续生效；手动位置必须与关卡允许位置相交。自动关联唯一固定账号冠位的行为保留。

`myGrandSvt` 只要求己方冠位、但没有 `activeGrandBoard` 位置限制时，也不再额外添加前排限制。其他明确要求首发的从者条件仍按其首发规则校验。

## 特殊编成的含义

这是同一个精确配队器处理关卡额外条件的搜索路径：人数范围、必须/禁止的身份或特性、首发资格、强制 NPC、多个系统助战、固定形象，以及己方冠位资格等。它仍按羁绊目标搜索，逐队核验人数、位置、库存和 COST；不是另一套羁绊收益公式，也不是 AI 降级。

特殊编成本身不意味着必须有冠位。是否需要真实己方冠位，要看该关卡的具体规则。要求真实己方冠位的关卡不能把尚未升冠的建议当作账号当前可出战队伍；“无冠位时推荐未来升冠选择”是单独的功能，本次位置修复未更改账号冠位身份或补充该建议流程。
