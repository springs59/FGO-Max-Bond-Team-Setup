2.1.6：内置三款可选 AI，并保留“不使用 AI”，默认关闭。

经典高起点 AI：成熟的单次起点策略，适合日常查询。扩展策略 AI：使用更丰富的配队特征，适合比较复杂条件。大数据神经 AI：使用 8192 组训练数据的神经网络，适合探索其擅长的条件。每款模型均附功能说明，选择保存在本机。

新查询只运行所选模型，最多推理一次；缓存命中不推理。起点方案经过实际规则校验，最终收益、COST 和助战方案仍由精确求解器验证。三款权重均随软件提供，可离线使用；更新或恢复模型保留用户选择。

不同条件下起点质量和耗时会变化，不能保证每款 AI 都优于旧框架。完整测试及起点退化记录见 docs/test-results/ai-three-models-2.1.6.md。旧版不支持的研究模型选择会迁移为关闭状态。

Windows 和 Android 沿用既有构建、签名和安装升级校验流程；具体构建验收结果见本次发布工作流。
