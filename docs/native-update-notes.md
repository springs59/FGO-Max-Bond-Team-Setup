本次版本为 2.0.2，Android versionCode 为 12，支持从 2.0.1 覆盖升级，保留账号、设置与本地计算数据。

方案与计算结果汇入同一个聚合库，相同内容自动去重。保留已实际算出的候选和完整曲线，包括非最优结果；不为保存而额外穷举未展开或被剪枝的组合。通用编队只保存成员、灵基、礼装、满破要求及位置，自由配队和所有账号共同调用，按当前库存、活动、关卡与 COST 核实。

点击「导出方案库」直接导出一个未压缩的 .jsonl 数据文件，自动包含全部已保存方案、候选、曲线和计算答案，无需勾选记录或选择导出内容。电脑、手机和网页可导入同一个文件迁移或合并；兼容旧压缩备份，重复去重，冲突答案保留并重新核实，损坏文件整份拒绝，不覆盖账号或设置。Windows、Android 流式写入同一个文件，较大库也无需按记录拆分导出。

完整有效条件相同时直接读取已保存答案，重启后仍可复用。账号名称、更新时间或货币变化不会触发重算；影响计算的库存、羁绊、活动、关卡或规则改变时重新核实并继续精确搜索。旧版答案保留，首次遇到旧归档的同条件查询时补齐候选保存，之后直接复用。手动从整个库找适配编队时，新结算也会保存，但不将库内候选称为全局最优。

保留软件内检查仓库发布、下载完整性校验、暂停续传与覆盖升级，以及既有 COST、曲线与最优进度修复。
