2.1.2（Android versionCode 19）按 2.1 的功能与计算路径发布。

AI 由用户选择：页面下方“AI 辅助与模型更新”可开启或关闭，默认关闭，选择保存在本机。只影响下次新查询；正在运行的任务保持原设置。AI 仅排序和提出经精算的候选，最终仍由精确求解器完成；不同条件的耗时可能不同。

AI 模型使用独立 GitHub ai-models 通道，点击“通过 GitHub 更新 AI”即可检查，无需重装软件。更新、恢复内置模型和失败回退都不会改变用户开关。下载校验兼容版本、特征结构、大小和 SHA-256，失败保留当前模型。账号数据不会上传。

普通查询不产生逐候选临时日志，不自动拟合或归档方案库。保留有界的已完成结果缓存，开关与模型权重分别隔离。没有给精确搜索增加计算时限。未恢复大规模方案库预计算，未发布未通过性能门槛的研究模型，未上传训练数据集。

Windows、Android 运行和安装升级检查，以及网页回归、AI 更新、精确结果对照和无候选日志检查均已通过。覆盖升级沿用原 APK 签名，保留账号、设置和本机数据。模型、训练数据制作与网络构建方法见仓库 docs/ai-2.1.2.md 和 docs/ai-200-hybrid.md。
