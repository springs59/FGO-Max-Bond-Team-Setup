本次版本为 2.0.6，Android versionCode 为 16，支持从 2.0.5、2.0.4、2.0.2 覆盖升级，保留账号、设置与本地计算数据。

数学计算完成后立即显示完整结果，全部已计算候选继续保存并明确显示状态，不再让结果展示等待所有候选入库。最终同机三轮中位数：首次可查看结果 1032.4 → 494.8 毫秒，等待减少约 52%；2.0.0 为 260.6 毫秒。全部入库仍需 1088.2 毫秒，本轮没有明显提速，仍显著高于 2.0.0，不能把提前显示当作完整保存提速。详见 [2.0.6 验证记录](verification-2.0.6.md)。

批量准备物理方案、原子写入、重复主键处理和归档批次调整保持候选内容与校验格式；内存缓冲与有界传输保护继续保留。已算完的答案与完整日志一起暂存，只有完整归档成功并核对记录数、字节数与校验后才提交精确缓存。结果显示后停止保存或进程中断，下次恢复全部已刷盘日志并复用已完成答案，无需重做已完成搜索。未完成的搜索和不完整日志不会当作完整最优答案。导出会等待当前结果保存及可恢复日志处理，仍直接导出整个聚合库为一个未压缩 JSONL 文件。

新增的生产 Worker 中断恢复、跨账号精确命中和实际界面导出等待验证通过，本版本另有三分钟真实计算与存储负载测试。上一版的 125 分钟测试范围保留在历史记录中，本版本未重新跑两小时耐久测试。

修复大规模、长时间计算时 Worker 消息复制及候选写入队列持续积压造成的内存溢出。大块输入和最终结果按不超过 64 KiB 的可转移消息分块，收到确认后再发送下一块；候选在计算 Worker 内以固定 256 KiB 缓冲写入磁盘，计算结束后逐批等待入库。取消或传输失败时及时释放待处理数据。

计算不设两小时或其他时长上限。Android 后台预计算也移除了固定 30 分钟等待上限，正常完成、用户暂停或系统停止时结束任务。暂停立即记录持久化控制状态，待启动的旧任务和延迟回调不会再把暂停改回运行或错误。取消或进程中断后，下次打开库或计算时恢复已刷入磁盘的完整候选；恢复候选不等于恢复搜索栈，未完成的搜索不会当作完整最优答案。磁盘或数据库写满时明确提示保存未完成并保留可恢复日志，空初始化残留不会影响以后保存。归档进度保留当前最优数值，另行显示已入库数量。

Android 处理主界面和后台 WebView 渲染进程退出：释放已失效的页面，主界面提供重新打开入口；后台在未暂停且未完成时最多恢复两次，复用已完成步骤，连续失败明确提示。旧页面回调不能覆盖新页面状态，账号和已保存的计算结果保留。

限制瞬态缓存的容量，淘汰只会触发重新计算，不删除已保存候选或改变求解公式、最优比较规则。全部已实际计算的候选和完整曲线仍保存，包括非最优结果。数学问题的状态空间仍会影响总内存和运行时间，本次修复不保证任意大规模查询立即完成。

保留同一个聚合库、跨账号共用物理编队、完整有效条件相同时跳过重算，以及一键导出整个库为一个未压缩 .jsonl 文件。备份迁移、自动去重、冲突保留与原子合并保持不变。保留软件内检查仓库发布、下载完整性校验、暂停续传与覆盖升级。
