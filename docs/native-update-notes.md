本次版本为 2.0.7，Android versionCode 为 17，支持从 2.0.6、2.0.5、2.0.4、2.0.2 覆盖升级，保留账号、设置与本地计算数据。

进一步优化完整候选入库：不可变内容按有界批量块保存，每条记录仍有独立索引；内容与索引原子提交，重复记录不新建块，物理方案日期更新复用原内容。已有单条记录继续兼容，不需清空或整体迁移库。复用同一份规范化文本生成原内容 ID 与 SHA-256 校验，公式、最优规则、账号有效条件与候选覆盖不变。

同机三轮中位数，首次全部入库完成 987.0 → 764.1 毫秒，约减少 23%；修改条件 380.8 → 320.1 毫秒，约减少 16%。独立归档段 494.6 → 251.2 毫秒，约减少 49%。结果可查看时间基本持平，以上完整入库改善没有拿提前显示替代保存结束。与 2.0.0 的 251.6 毫秒旧流程相比，完整流程仍约 3 倍，尚未恢复原速度。详见 [2.0.7 验证记录](verification-2.0.7.md)。

所有首次候选及物理方案逐条 ID、内容、校验和与 2.0.6 对照一致。整批写入失败回滚、重复不增块、创建日期保留、旧/新存储共存、单文件备份、迁移合并、冲突保留和缺块拒绝测试通过；实际界面导出等待、杀 Worker 恢复及跨账号精确复用通过。本版另有约三分钟真实计算与存储负载验证，未重新跑两小时耐久测试。

沿用计算完成后先显示结果、在同一个 Worker 中继续保存全部候选的行为。完整归档并核对数量、字节和校验后才成为精确缓存；显示后停止保存或进程中断，下次恢复日志并复用已完成答案。全量候选保留，导出仍直接生成整个聚合库的一个未压缩 JSONL 文件，不选择内容、不暴露内部存储块。

修复大规模、长时间计算时 Worker 消息复制及候选写入队列持续积压造成的内存溢出。大块输入和最终结果按不超过 64 KiB 的可转移消息分块，收到确认后再发送下一块；候选在计算 Worker 内以固定 256 KiB 缓冲写入磁盘，计算结束后逐批等待入库。取消或传输失败时及时释放待处理数据。

计算不设两小时或其他时长上限。Android 后台预计算也移除了固定 30 分钟等待上限，正常完成、用户暂停或系统停止时结束任务。暂停立即记录持久化控制状态，待启动的旧任务和延迟回调不会再把暂停改回运行或错误。取消或进程中断后，下次打开库或计算时恢复已刷入磁盘的完整候选；恢复候选不等于恢复搜索栈，未完成的搜索不会当作完整最优答案。磁盘或数据库写满时明确提示保存未完成并保留可恢复日志，空初始化残留不会影响以后保存。归档进度保留当前最优数值，另行显示已入库数量。

Android 处理主界面和后台 WebView 渲染进程退出：释放已失效的页面，主界面提供重新打开入口；后台在未暂停且未完成时最多恢复两次，复用已完成步骤，连续失败明确提示。旧页面回调不能覆盖新页面状态，账号和已保存的计算结果保留。

限制瞬态缓存的容量，淘汰只会触发重新计算，不删除已保存候选或改变求解公式、最优比较规则。全部已实际计算的候选和完整曲线仍保存，包括非最优结果。数学问题的状态空间仍会影响总内存和运行时间，本次修复不保证任意大规模查询立即完成。

保留同一个聚合库、跨账号共用物理编队、完整有效条件相同时跳过重算，以及一键导出整个库为一个未压缩 .jsonl 文件。备份迁移、自动去重、冲突保留与原子合并保持不变。保留软件内检查仓库发布、下载完整性校验、暂停续传与覆盖升级。
