本次版本为 2.0.1，Android versionCode 为 11，支持从 2.0.0 覆盖升级，保留账号、设置与本地计算数据。

新增「全局方案／计算库」。用户完成的查询和曲线自动保存。通用方案只保存成员、灵基、礼装、满破要求和位置，不绑定账号、库存、羁绊等级或旧收益；自由配队和各账号共同调用，使用时按当前库存、关卡、活动和 COST 重新核实、结算。

有效条件相同的查询直接复用答案；库存等条件变化后，用仍合法的通用方案帮助继续精确核算，不把旧账号的最优直接当作新答案。冠位、固定系统助战等特殊方案会保存供迁移，暂不支持普通方案直接调用。

支持导出全部或勾选的方案、计算记录，在网页、电脑和手机之间迁移并合并。重复记录去重，冲突结果保留并重新核算，损坏的备份整份拒绝合并；不覆盖账号或设置。纯方案备份不携带账号状态，完整计算备份含当次计算槽位和收益，不含登录回包。较大库可勾选分批导出。

保留软件内检查仓库发布、下载校验、暂停续传与覆盖升级，以及既有 COST、曲线与最优进度修复。Windows 0.1.6／0.1.7 的旧更新器可能需要手动下载 EXE 覆盖安装一次，无需卸载；之后可使用软件内更新。Android 可使用现有软件内更新。
